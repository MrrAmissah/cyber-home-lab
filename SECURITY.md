# Scope and rules of engagement

This repository documents security testing and defensive engineering **only against systems I own or have explicit written permission to test**: my own virtual machines, containers and lab network.

- Nothing here is to be run against third-party systems.
- Exploitation steps in write-ups are recorded for learning and reproduction inside the lab described in `infra/`.
- If you believe something in this repository is unsafe or misattributed, open an issue or contact me through my GitHub profile.

Testing without authorisation is an offence under Ghana's Cybersecurity Act 2020 (Act 1038) and equivalent laws elsewhere.
